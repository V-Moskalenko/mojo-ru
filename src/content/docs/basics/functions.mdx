Большая часть того, что вы знаете о функциях из Python, работает и здесь.
Но есть одно понятие, которого в Python нет вовсе, — и именно с него
начинается настоящая сила Mojo.

## Сигнатура

```
def имя[параметры](аргументы) -> тип_возврата:
    тело
```

Обязательно только имя и тело. Всё остальное — по необходимости, кроме
типов аргументов: они нужны всегда.

```mojo
def greet(name: String, greeting: String = "Привет") -> String:
    return greeting + ", " + name + "!"
```

Функция без возвращаемого значения просто не имеет стрелки, либо пишется
`-> None` — оба варианта равнозначны.

## Аргументы и параметры — это разные вещи

В Python «аргумент» и «параметр» — синонимы, и путать их не страшно.
В Mojo это два разных механизма, и разница принципиальная:

| | Аргументы | Параметры |
| --- | --- | --- |
| Скобки | круглые `( )` | квадратные `[ ]` |
| Когда известны | во время выполнения | **на этапе компиляции** |
| Что с ними делает компилятор | передаёт в функцию | генерирует отдельную версию функции |

```mojo
def repeat[count: Int](text: String):
    for _ in range(count):
        print(text, end=" ")
    print()


def main():
    repeat[3](String("эй"))
```

<Result>
эй эй эй
</Result>

Здесь `count` — параметр: компилятор знает, что повторов ровно три, и может
развернуть цикл в три вызова `print` без всякого счётчика. `text` — обычный
аргумент, его значение станет известно только при запуске.

<Aside type="tip" title="Зачем это нужно">
  Из этого различия растёт вся производительность Mojo. Размерность вектора,
  длина буфера, тип элемента — если они известны заранее, компилятор
  подставляет их и генерирует специализированный машинный код. В Python
  такой информации у интерпретатора нет никогда.

  Подробно — в разделе [Метапрограммирование](/meta/parameters/). Пока
  достаточно запомнить: квадратные скобки — это «известно при сборке».
</Aside>

## Значения по умолчанию и именованные аргументы

Работают как в Python:

```mojo
greet("Мир")                                # позиционно
greet(name="Mojo", greeting="Здравствуй")   # по именам
```

Обязательные аргументы идут перед аргументами со значением по умолчанию.
Можно сделать аргумент **только именованным**, поставив перед ним звёздочку:

```mojo
def connect(host: String, *, timeout: Int = 30) -> String:
    return host + ":" + String(timeout)


def main():
    print(connect("example.com", timeout=5))
```

<Result>
example.com:5
</Result>

Такие аргументы нельзя передать позиционно — это защита от вызовов вида
`connect("example.com", 5, True, False)`, где через полгода никто не помнит,
что означает каждое число.

## Вариативные аргументы

```mojo
def total(*values: Int) -> Int:
    var sum = 0
    for value in values:
        sum += value
    return sum


def main():
    print(total(1, 2, 3, 4))
```

<Result>
10
</Result>

Обратите внимание: у вариативных аргументов тоже есть тип. `*values: Int`
означает «сколько угодно целых», а не «сколько угодно чего угодно».

## Перегрузка

Одно имя может обслуживать разные типы — компилятор выберет нужную версию
по типам аргументов:

```mojo
def describe(value: Int):
    print("целое:", value)


def describe(value: String):
    print("строка:", value)


def main():
    describe(42)
    describe(String("сорок два"))
```

<Result>
целое: 42
строка: сорок два
</Result>

Это не «магия»: выбор происходит на этапе компиляции, накладных расходов
при вызове нет.

<CompilerError msg="error: redefinition of function 'show' with identical signature">
  <Fragment slot="meaning">
    Две функции с одним именем и одинаковыми типами аргументов. Компилятору
    нечем их различить.
  </Fragment>
  <Fragment slot="fix">
    Перегрузка различает функции по типам аргументов, а не по именам или
    типу возврата. Дайте разные имена либо разные типы.
  </Fragment>
</CompilerError>

## Возврат нескольких значений

Отдельного синтаксиса нет — используется кортеж:

```mojo
def divide(a: Int, b: Int) -> Tuple[Int, Int]:
    return (a // b, a % b)


def main():
    var result = divide(17, 5)
    print(result[0], result[1])
```

<Result>
3 2
</Result>

## Что функция делает с аргументом

По умолчанию аргумент передаётся **только для чтения**: функция видит
значение, но изменить его у вызывающего кода не может. Если менять нужно —
пишется `mut`:

```mojo
def bump(mut counter: Int):
    counter += 1


def main():
    var counter = 10
    bump(counter)
    print(counter)
```

<Result>
11
</Result>

Кроме `mut` есть ещё `var` (передача владения), `ref` и `out` — им посвящена
[отдельная глава](/ownership/conventions/), потому что за ними стоит вся
модель памяти языка.

<CompilerError msg="error: 'mut' arguments must not have defaults">
  <Fragment slot="meaning">
    У изменяемого аргумента нельзя задать значение по умолчанию.
  </Fragment>
  <Fragment slot="fix">
    Логично: менять нечего, если аргумент не передали. Уберите значение
    по умолчанию либо сделайте аргумент обычным.
  </Fragment>
</CompilerError>

## Вложенные функции и рекурсия

Обе привычные возможности на месте:

```mojo
def factorial(n: Int) -> Int:
    if n <= 1:
        return 1
    return n * factorial(n - 1)


def main():
    def double(x: Int) -> Int:
        return x * 2

    print(double(21), factorial(10))
```

<Result>
42 3628800
</Result>

## Функции, которые могут бросить исключение

Помечаются словом `raises`:

```mojo
def parse(text: String) raises -> Int:
    return Int(text)
```

Вызывающий код обязан это учесть: либо обернуть вызов в `try`, либо тоже
объявить себя `raises`. В Python исключение может прилететь откуда угодно;
в Mojo способность бросать исключение — часть контракта функции.

## Докстринги проверяет компилятор

Приятная мелочь, которой нет в Python:

```text
warning: doc string summary should begin with a capital letter
or non-alpha character, but this begins with 'm'
```

Mojo следит за оформлением документации к функциям — и подсказывает,
если первая строка докстринга написана небрежно. Мелочь, а дисциплинирует.

  <QuizItem q="Чем параметр в квадратных скобках отличается от аргумента в круглых?">
    Параметр известен на этапе компиляции, и компилятор генерирует под
    каждое его значение отдельную специализированную версию функции.
    Аргумент передаётся во время выполнения. Из этого различия и растёт
    производительность Mojo.
  </QuizItem>
  <QuizItem q="Можно ли перегрузить функцию, изменив только тип возвращаемого значения?">
    Нет. Перегрузка различает функции по типам аргументов. Две функции
    с одинаковыми аргументами дадут ошибку `redefinition of function
    with identical signature`, даже если возвращают разное.
  </QuizItem>
  <QuizItem q="Как вернуть из функции два значения?">
    Кортежем: `-> Tuple[Int, Int]` и `return (a, b)`. Отдельного синтаксиса
    множественного возврата, как и в Python, нет — там тоже возвращается
    кортеж, просто скобки не пишут.
  </QuizItem>
</Quiz>
