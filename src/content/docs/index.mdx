## Почему этот курс

<CardGrid>
  <Card title="Русский язык без машинного перевода" icon="translate">
    Термины подобраны осознанно и используются одинаково на всех страницах.
    При первом упоминании — русский вариант и оригинал в скобках, чтобы вы
    могли гуглить на английском и читать официальную документацию.
  </Card>
  <Card title="Windows — полноценная платформа" icon="laptop">
    Mojo не работает в Windows напрямую, только через WSL. Здесь это не
    сноска мелким шрифтом, а отдельная большая глава: WSL2, uv, VS Code
    Remote, SSH-ключи и разбор типичных ошибок установки.
  </Card>
  <Card title="Код, который компилируется" icon="approve-check">
    Каждый пример лежит в репозитории отдельным файлом и прогоняется в CI.
    Под примерами показан настоящий вывод программы, а не придуманный.
  </Card>
  <Card title="Опора на официальный источник" icon="document">
    Теория сверена с официальным мануалом Modular. Мы отдельно отмечаем
    конструкции, которые устарели: `fn`, `let`, `inout`, `@value` —
    в интернете полно статей, где они ещё живы.
  </Card>
</CardGrid>
