Mojo — компилируемый язык, который с самого начала рассчитан на современные
векторные инструкции процессора. Отсюда требования жёстче, чем у Python:
на очень старой машине он просто не запустится. Проверить это лучше до
установки, а не после сорока минут скачивания.

## Коротко

| Что | Требование |
| --- | --- |
| Linux | glibc 2.34 или новее. Официально поддерживается Ubuntu 22.04 LTS и новее |
| macOS | **Только Apple Silicon.** Маки на Intel не поддерживаются |
| Windows | Только через WSL — нативной версии нет |
| Процессор x86-64 | Уровень `x86-64-v3`: Haswell и новее, примерно с 2013 года |
| Процессор ARM | Neoverse N1 и новее (на Linux — AWS Graviton2 и новее) |
| Оперативная память | Минимум 8 ГиБ |
| Дополнительно на Linux | Компилятор C: `cc`, `gcc` или `clang` |
| Дополнительно на macOS | Xcode или Command Line Tools версии 16+ |

Требуемые наборы инструкций для x86-64: **AVX, AVX2, BMI1, BMI2, F16C, FMA,
LZCNT, MOVBE, XSAVE**. Если хотя бы одного нет — Mojo не запустится.

<Aside type="caution" title="Маки на Intel — мимо">
  Это частый источник разочарования: MacBook 2019 года прекрасно работает,
  Python на нём летает, а Mojo на него поставить нельзя. Поддерживается
  только Apple Silicon — M1 и новее. Обходного пути нет: под Intel-маки
  сборки компилятора просто не существует.
</Aside>

## Как проверить процессор

<Tabs syncKey="os">
  <TabItem label="Windows">

Откройте PowerShell и выполните:

```powershell
Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores
```

Название процессора скажет главное. Ориентир простой: **Intel Core
4-го поколения (Haswell, 2013) и новее** либо **AMD Ryzen любого поколения**
и AMD Excavator/Zen — подходят. Core i7-2600, i5-3470 и прочие ранние
поколения — нет.

Точную проверку наборов инструкций проще сделать уже внутри WSL — командой
из соседней вкладки «Linux».

  </TabItem>
  <TabItem label="Linux">

```bash
lscpu | grep -o -E 'avx2|bmi1|bmi2|f16c|fma|lzcnt|movbe|xsave' | sort -u
```

<Result label="Ожидаемый вывод">
avx2
bmi1
bmi2
f16c
fma
movbe
xsave
</Result>

Если в выводе нет `avx2` — процессор не подойдёт. Обратите внимание:
`lzcnt` в `lscpu` часто отображается как `abm`, так что его отсутствие
в этом списке само по себе не приговор.

Заодно проверьте версию glibc — нужна 2.34 или новее:

```bash
ldd --version | head -1
```

  </TabItem>
  <TabItem label="macOS">

```bash
sysctl -n machdep.cpu.brand_string
```

Если в ответе `Apple M1`, `Apple M2`, `Apple M3` и так далее — всё хорошо.
Если `Intel(R) Core(TM)...` — Mojo на этой машине работать не будет.

  </TabItem>
</Tabs>

## Сколько нужно места

Официальная документация размер не оговаривает. По факту закладывайте:

- около **2 ГБ** на сам Mojo и стандартную библиотеку внутри окружения проекта;
- ещё **3 ГБ** на Windows — под WSL и Ubuntu;
- плюс место под кэш сборки, которое растёт с размером проекта.

Пять свободных гигабайт — комфортный минимум для начала.

<Aside type="tip" title="Про оперативную память">
  8 ГиБ — это минимум для самой разработки. На Windows учтите, что WSL
  забирает память у системы: при 8 ГБ на всё про всё компиляция и открытый
  браузер начнут конкурировать. Если памяти ровно 8 ГБ, [ограничьте
  аппетиты WSL](/install/windows-wsl/) через `.wslconfig`.
</Aside>

## Видеокарта — только если нужен GPU

Для всего курса, кроме последней главы про GPU, видеокарта не нужна вовсе.
Если планируете считать на GPU, поддерживаются:

- **NVIDIA** — драйвер 580 и новее: B200, H100, A100, L4, T4, а также
  игровые RTX;
- **AMD** — драйвер 6.3.3 и новее: MI355X, MI300X, MI250X и часть Radeon RX;
- **Apple** — чипы M1–M5 на macOS Sequoia 15+ с Xcode 16+.

  <QuizItem q="У меня MacBook Pro 2019 на Intel. Что делать?">
    Локально Mojo не поставить — поддерживается только Apple Silicon.
    Варианты: удалённая машина с Linux (см. главу

  </QuizItem>
  <QuizItem q="Почему Mojo требует AVX2, а Python — нет?">
    Python исполняется интерпретатором, который собран под минимальный
    общий набор инструкций. Mojo компилируется в машинный код и опирается
    на векторные операции как на базовый механизм — тип `SIMD` встроен
    в язык. Требование современного процессора — плата за то, ради чего
    язык и создавался.
  </QuizItem>
</Quiz>
