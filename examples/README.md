# Примеры курса

Каждый пример здесь — настоящий файл `.mojo`, который компилируется и
запускается в CI. Рядом с ним лежит файл `.out` с ожидаемым выводом.

```
examples/
  <раздел>/<страница>/<пример>.mojo   исходник
  <раздел>/<страница>/<пример>.out    ожидаемый вывод
```

Проверить локально (нужен установленный Mojo):

```bash
npm run examples:check
```

Правило проекта: **ни один блок кода на сайте не должен существовать
только внутри markdown**. Если пример можно запустить — он живёт здесь.

Программы для видеокарты (`projects/gpu-intro/`) устроены так же, но
с оговоркой: у CI нет GPU, поэтому вывод `.out` — это вывод ветки для
процессора. Ветка для видеокарты вместе с ядрами дополнительно
собирается под NVIDIA (`sm_86`) и AMD (`gfx1100`) флагом
`--target-accelerator`, но не запускается.
