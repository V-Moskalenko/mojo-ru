# Рабочие заметки

Внутренние материалы для авторов курса: выжимки из официальной документации
с пометками «требует проверки». В сайт не попадают.

- `mojo-1.0-syntax-research.md` — сверка синтаксиса Mojo 1.0 с мануалом:
  что изменилось относительно бет и версий 2023–2025, таблица
  «устарело → актуально», ссылки на источники.
- `mojo-1.2-migration.md` — переход курса с 1.1 на 1.2: что поймала и чего
  не поймала проверка, проверенные факты о `match` и прочих новинках.
