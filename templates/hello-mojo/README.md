# Шаблон проекта на Mojo

Готовое окружение, чтобы попробовать Mojo, ничего не устанавливая:
откройте эту папку в GitHub Codespaces — Mojo и расширение VS Code
поставятся сами.

Локально (Linux, macOS или WSL):

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv add mojo
uv run mojo hello.mojo
```
