# Как помочь проекту

Спасибо, что хотите помочь. Ниже — правила, которые держат курс цельным.

## Правки текста

Самый простой путь: внизу каждой страницы сайта есть ссылка
«Редактировать страницу» — она ведёт прямо в редактор GitHub.

## Правила для примеров кода

1. Любой пример, который можно запустить, живёт в `examples/` отдельным
   файлом `.mojo`. Рядом кладётся файл `.out` с ожидаемым выводом.
2. Перед отправкой прогоните `npm run examples:check`.
3. Код пишется под **Mojo 1.0**: только `def`, только `var`, конвенции
   `mut` / `var` / `ref` / `out`, декоратор `@fieldwise_init`.
   Никаких `fn`, `let`, `inout`, `borrowed`, `owned`, `@value`.

## Правила для текста

- Термины берутся из [словаря](src/content/docs/reference/glossary.mdx).
  Хотите изменить перевод термина — сначала обсуждение, потом правка
  сразу на всех страницах.
- При первом употреблении термина: русский вариант, оригинал в скобках курсивом.
- Обращение к читателю — на «вы» со строчной буквы.
- Никакого «просто», «легко», «очевидно»: если бы это было очевидно,
  читатель бы сюда не пришёл.
- Каждая глава заканчивается блоком «Проверь себя» и ссылкой на следующую.

## Новые главы

Структура курса зафиксирована в `scripts/make-stubs.mjs`. Хотите добавить
главу — сначала откройте issue с обоснованием: почему она нужна и куда
встраивается.

## Лицензии

Отправляя правку, вы соглашаетесь, что текст публикуется под CC BY 4.0,
а код — под Apache 2.0.

## Рабочий процесс

```bash
git checkout -b правка/короткое-описание
# правки
npm run build          # сборка проверяет и ссылки тоже
npm run format         # причёсывает исходники (главы не трогает)
git commit -m "текст: поправил главу про WSL"
git push -u origin правка/короткое-описание
```

Дальше — pull request. CI соберёт сайт и проверит внутренние ссылки,
а при изменении примеров прогонит их на настоящем компиляторе Mojo.

Префиксы коммитов, которые мы используем: `текст:`, `код:`, `дизайн:`,
`инфра:`, `правка:`. Строгих требований нет, главное — понятно.

## Локальная проверка примеров

Проверка запускает настоящий компилятор, поэтому нужен Linux, macOS или WSL
с установленным Mojo:

```bash
uv run npm run examples:check
# либо, если Mojo лежит в другом месте:
MOJO_CMD=/путь/к/mojo npm run examples:check
```
